ADAM - Neon Genesis Evangelion (N64, 1999, Japan) as a native Windows program
==================================================================================
Version {VERSION}

Made with AI. It has not been reviewed by experienced developers, so expect mistakes.

This package contains NO game data. You need your own ROM of the game (Japanese release, .z64, 32 MB).

1. Unzip into a folder anywhere you like (one you can write to) and run adam.exe. It creates a "data" folder
   next to itself on the first start.
2. In the launcher, choose "Load ROM" and pick your ROM file. It is checked and copied into the "data" folder
   next to adam.exe, so you only do this once. Saves and settings are stored there too.
3. Choose "Start Game". The game's code is translated from your ROM when the game starts (well under a second).

Controls (change them in Settings -> Controls):
  Stick       arrow keys        / left stick
  A, B        X, C              / A, X
  Z           Z                 / left trigger
  Start       Enter             / Start
  L, R        A, S              / LB, RB
  C buttons   I J K L           / right stick
  D-pad       T F G H           / D-pad
  Menu        Esc               / Back      (pauses the game)
  Fast-forward  hold Tab / right trigger (2x speed; on/off in Settings -> General)
  Rewind        hold Backspace / click the left stick, in missions (up to 10 s; on/off in Settings -> General)
  Debug: P pauses and resumes, F9 writes a RAM dump

Extras:
  Settings -> Bezels: artwork from the game in the black bars beside the picture (pick a picture, brightness,
    black & white, position and size).
  Launcher -> Background: the same choices for the launcher's background.
  Settings -> General -> Reset Game: restarts the game (like the console's reset).
  Settings -> General -> English Game Text: the game's captions, briefings, cutscene lines, mission titles, controls
    screens and menu prompts in English (on by default). The staff credits are still Japanese.
  Settings -> General -> Steady 3D: try it if the 3D scenes flicker (off by default; on some PCs it stops the sound).
  Settings -> General -> English Subtitles: an English line at the bottom of the screen while a character speaks
    (on by default). Not every voice clip has one yet. To correct or add lines, put a subtitles_en.txt in the data
    folder (format: see the project's runtime\subtitles folder).
  Settings -> Texture Packs: HD texture packs (.rtz files) put in data\mods or dropped on the window; switch them on
    and off here. Settings -> General -> Save Textures saves the game's textures to data\texture_dump, to make a pack
    (see the project's README, "HD texture packs").

Graphics default to the original N64 picture at 2x resolution. Settings -> Graphics -> Resolution -> 1080p renders
at 1080p whatever the window's size (pair it with Fullscreen: F11 or Alt+Enter). Higher resolutions (1080p, or
"Auto" in a large window) currently show thin lines across some scaled backgrounds.

Requirements: Windows 10/11 x64, a GPU with Direct3D 12 or Vulkan.
